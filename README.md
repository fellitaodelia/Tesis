- `APE Model Harga Nominal XGBoost Data Uji.csv`: Nilai APE hasil prediksi menggunakan XGBoost pada masing-masing provinsi untuk data uji harga nominal GKP di tingkat petani
- `APE Model Harga Riil EnbPI.csv`: Nilai APE hasil prediksi menggunakan EnbPI pada masing-masing provinsi untuk data harga riil GKP di tingkat petani

- `APE Model Harga Riil XGBoost Data Uji.csv`: Nilai APE hasil prediksi menggunakan XGBoost pada masing-masing provinsi untuk data uji harga riil GKP di tingkat petani
